Siyak is a desktop app for reading and researching the Quran: Arabic text and translations side by
side, tafsir, word and root analysis, search and notes, in one interface that stays simple until you
ask for more.

It is **pre-alpha**: there is no download yet. The app is built in the open; see the development
guide if you would like to try it or contribute.

- **Offline:** everything runs on your computer; no account, no server.
- **Free and open source:** `MIT OR Apache-2.0`; every data source keeps its own license.
- **No API key needed** for reading, comparison, root analysis, search and notes.
